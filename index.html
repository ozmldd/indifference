ABOUT

A simple story game, built for fun and to practise C++. No engine and no framework — the game loop, collision, camera and menus are all written by hand on top of SDL3.

FEATURES

  • Hand-rolled game loop with delta-time movement
  • Two-pass axis-separated collision with a float epsilon for grazing contacts
  • Held-button jumping, so bunny hopping chains naturally
  • Tile-based levels, switchable at runtime
  • NPC dialogue with per-character lines and word wrap
  • Title screen, options menu with a volume slider, and a pause menu
  • Save and load — level and position persist between sessions
  • Scrolling end credits and an epilepsy warning screen
  • Debug overlay drawing colliders and state

BUILDING

Needs a C++17 compiler, SDL3, SDL3_image, SDL3_mixer (3.x) and GLM.

g++ -std=c++17 -Wall gametest.cpp -o indifference.exe \
    -I"path/to/SDL3/include" -I"path/to/glm" \
    -L"path/to/SDL3/lib" \
    -lSDL3 -lSDL3_image -lSDL3_mixer

SDL3_mixer 3.x is a full API redesign from 2.x — the 2.x snippets you find online will not compile against it.

LEVEL FORMAT

Levels are 2D integer arrays, read tile by tile in createTiles.

ValueTile
0Empty
1Grass — solid
2Dirt — solid
3Background tile, no collider
4Player spawn
5Event block — cutscene / level change
6, 7NPCs
8End block — rolls the credits
