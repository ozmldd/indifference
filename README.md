# Indifference
Indifference is a story game written entirely in c++ using the SDL3 library with the help of some of my friends (mostly for the assets and art)

## Try it for yourself:

https://ozmld.itch.io/indifference
Just download the zip, extract into a folder (or to desktop, I recommend folder though since it's more organized that way) and run the executable only, compatible for windows, not 100% for other OS's

## Features
- audio slider (missing the gameplay music but does have the menu music)
- interactive buttons
- naming one's player

## Controls:
it says in the game but in advance here are the controls:
- Arrow Keys: Move
- Z: interact with characters
- W: continue dialog/next
- hold shift to sprint
